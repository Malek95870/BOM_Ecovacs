⚙ Paramétrage de l'outil

1. Dossier des BOM
Aucun dossier choisi

Sélectionnez le dossier OneDrive synchronisé sur ce PC (ex. OneDrive - Fnac Darty › BOM ECOVACS). Le choix est mémorisé.

2. Ouverture « Excel brut »
Méthode Excel en ligne :

Copie téléchargée fonctionne partout (GitHub ou PC) : le fichier lu depuis votre dossier OneDrive synchronisé est enregistré dans Téléchargements puis s'ouvre dans Excel d'un clic.

Excel en ligne / bureau nécessitent l'adresse du dossier : ouvrez-le dans OneDrive (navigateur) et copiez l'adresse de la barre. Si une page blanche s'affiche, essayez la méthode B ou C avec « 🧪 Tester ».

🧺 Panier de pièces

Pièces sélectionnées dans les BOM. Ajustez les quantités puis copiez la liste (colonnes séparées par tabulation : à coller dans NOMAD, Excel ou un mail).

⚖ Comparer deux BOM

Comparez la BOM ouverte avec une autre version ou un modèle proche : pièces ajoutées, supprimées ou modifiées (désignation, quantité).

❓ Aide rapide — BOM Ecovacs

  • Trouver une BOM : tapez le modèle (ex. DEEBOT X2 OMNI) puis Entrée ou « 📖 Liseuse ».
  • Trouver une pièce dans toutes les BOM : tapez sa référence (ex. 201-2228-1707). La liste des modèles qui l'utilisent s'affiche en haut ; « Voir la pièce » ouvre directement la bonne ligne.
  • ⭐ Favoris : cliquez sur l'étoile d'un modèle pour le retrouver en tête de la page d'accueil.
  • Dans la liseuse : filtrez les pièces, « 🌐 Traduire en FR », cliquez sur une photo pour zoomer (molette, +/−), « 🖨 Imprimer » pour une fiche pièce.
  • Références soulignées dans les remarques : cliquez pour sauter vers la pièce citée.
  • ⚠ Bandeau orange : la pièce est remplacée par une nouvelle référence — commandez celle indiquée.
  • ⚖ Comparer (dans la liseuse) : choisissez une autre BOM pour voir les pièces ajoutées, supprimées ou modifiées — pratique entre deux versions d'un même modèle.
  • 🧺 Panier : « ＋ Panier » sur chaque pièce, puis copiez la liste pour NOMAD ou envoyez-la par mail.
  • Modèle introuvable : bouton « Demander la BOM au référent ».
